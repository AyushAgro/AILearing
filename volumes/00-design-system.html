Scaled Dot-Product Attention

A sample chapter showing the problem-first structure, bullet-first writing, callouts, code, tables, diagrams and maths.

The Engineering Problem

A recurrent network must compress an entire prefix into a fixed-size state and process tokens sequentially. Long-range dependencies degrade, and training cannot be parallelised across time.

Possible Solutions

  • Bigger recurrent state: more memory per step, still sequential.
  • Convolutions: parallel, but receptive field grows only with depth.
  • Attention: every token reads every other token directly, in parallel.
Key Idea
  • Attention is a differentiable key–value lookup.
  • Each query scores every key; the softmax of the scores weights the values.
  • Cost is O(T^2 d) in sequence length T.

How It Works

Given queries Q, keys K and values V, each of shape (T, d_k):

\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
  1. Score every query against every key: scores = q @ k.T.
  2. Scale by 1/\sqrt{d_k} so score variance stays near 1.
  3. Apply the causal mask (decoder models only).
  4. Softmax over keys; multiply by values.

Scaling and numerical stability

Without the scale, dot products of unit-variance vectors have variance d_k, which pushes softmax into saturation and shrinks gradients.

Why subtract the maximum in softmax

Softmax is shift-invariant, so subtracting the row maximum changes nothing mathematically but prevents exp overflow for large logits.

Implementation

max |ours - torch.sdpa| = 4.4e-16   (B=2, T=5, D=8, causal=True)
Implementation Notes
  • Use -np.inf, not -1e9, so masked weights are exactly zero.
  • Check parity against torch.nn.functional.scaled_dot_product_attention.
Trade-off
  • Materialising the T \times T matrix costs memory quadratic in context length; production kernels (FlashAttention) never store it.
Risk
  • A missing causal mask leaks future tokens during training: loss looks excellent, generation is useless. Always test that masked weights are zero.
Research Frontier
  • Linear attention and state-space models trade exact attention for O(T) cost; see Volume 7.

Trade-offs and Comparison

Advantages

  • Fully parallel across tokens.
  • Direct long-range paths.
  • Simple, well-understood gradients.

Disadvantages

  • Quadratic memory and compute.
  • No inherent notion of order.
  • KV cache grows with context at inference.

Failure Modes

  • Softmax overflow from unscaled scores in FP16.
  • Padding tokens attended to because the padding mask is missing.

Real Products

Documented vLLM stores the KV cache in fixed-size blocks (PagedAttention), per Kwon et al. (2023).

Inferred Large hosted assistants very likely use prefix caching for long system prompts; providers expose it as a priced feature, but internals are not public.
